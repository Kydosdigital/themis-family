# Supabase backend

Supabase is the selected backend platform for Themis Family.

This directory is the durable source-controlled database/backend workspace.

## Structure

- `migrations/`: ordered PostgreSQL schema, constraint, index and RLS changes
- `functions/`: Supabase Edge Functions where server-side logic is appropriate
- `seed.sql`: non-sensitive local development seed data only
- `config.toml`: generated by `supabase init` when the local CLI foundation task runs

Do not commit generated local state from `supabase/.temp/`.

## Source of truth

Durable database changes belong in migrations, not only in the Supabase Dashboard.

Production-sensitive operations must remain consistent with:
- `docs/19_DATA_MODEL.md`
- `docs/24_SECURITY_REQUIREMENTS.md`
- `docs/29_API_AND_BACKEND_REQUIREMENTS.md`
- DEC-54 and DEC-60

## MCP

The repo includes a project-scoped Supabase MCP declaration in `.mcp.json`.

Set `SUPABASE_PROJECT_REF` in the local shell before starting Claude Code, then authenticate the MCP server interactively.

Do not store the OAuth/access token in the repository.

Until the Themis Supabase project exists, the MCP declaration is intentionally not usable.
